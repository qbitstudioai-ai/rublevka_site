## Публичные критические исправления

- У `/meropriyatiya` добавлен canonical `/meropriyatiya` с абсолютной `metadataBase` из `APP_URL`, поэтому production не получает fallback-домен `localhost`.
- `.superpowers/**` исключен из ESLint, при этом продуктовый код продолжает проверяться.
- Лента фильтров карты получила подсказку о горизонтальной прокрутке, связанную с группой через `aria-describedby`; на desktop она скрыта, когда фильтры становятся вертикальными.
- Все изменения книги поддерживают `prefers-reduced-motion`: открытие книги и перелистывание не зависят от обязательной анимации.

## Ограничения среды

- E2E-раннер events-приложения не запускался: в его конфигурации отсутствует локально установленный Playwright Chromium. Его production build и TypeScript прошли успешно.
- Реальные административные мутации, публикации, удаления, регистрация гостей и Telegram-уведомления в этой проверке не выполнялись. Их контрактная часть покрыта изолированными database-тестами.
