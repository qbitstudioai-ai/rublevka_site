В рисунке узнаются два фронтона с резными карнизами, зелёная кровля, два этажа тёмного сруба, белые наличники и центральное крыльцо. Живописный свет, древесные линии и резьба упрощены для читаемости на масштабе карты. Видимые метки вынесены вбок, а исходные зоны нажатия и стрелки входов сохранены.

Браузерная проверка сверила геометрию всех 30 объектов, проверила фильтры, карточки, переход в проживание, фокус с клавиатуры, приближение, перетаскивание, мобильные жесты и нижнюю панель. `npm run check` и production-сборка прошли.

Размер gzip для production-HTML вырос с 33 590 до 35 625 байт. Суммарный gzip начальных JS-файлов изменился со 190 734 до 190 805 байт. Сравнение выполнено с художественной картой из PR №9.
