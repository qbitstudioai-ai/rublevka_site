Скриншоты сделаны в Chromium на production-сборке. Размер окна на компьютере — 1440 × 1080, на телефоне — 390 × 844. На ширине 320 px дополнительно проверили отсутствие горизонтальной прокрутки страницы.

Дополнительно проверены клавиатурное открытие карточки, возврат к видимой строке списка, панорамирование к маркеру при фокусе, масштабирование двумя пальцами и переход из книги. Ошибок в консоли браузера нет. В HTML присутствуют заголовок, canonical, структурированные данные, все 30 объектов и 16 отмеченных входов.
