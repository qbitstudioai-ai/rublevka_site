# План проекта «Рублевка»

**Цель:** интерактивный сайт-экосистема загородного комплекса в стиле древнерусской сказки: «Уехать из города, чтобы насладиться тишиной».

## Этапы

- [x] **0. Концепция и требования.** Определены атмосфера, направления функционала, ограничения по объёму текста и базовые SEO-требования. Результат: [README](../README.md).
- [x] **1. Архитектурный фундамент.** Next.js, TypeScript, структура приложения и правила разработки. [PR #1](https://github.com/qbitstudioai-ai/rublevka_site/pull/1) объединён в `main` ([коммит](https://github.com/qbitstudioai-ai/rublevka_site/commit/34d7d3347952fb5204ff70c22d0de78e8eafffdd)).
- [x] **2. Визуальная система и прототип.** Интерактивная сказочная книга, адаптивные главы, перелистывание и дизайн-токены. [PR #2](https://github.com/qbitstudioai-ai/rublevka_site/pull/2) объединён в `main` ([коммит](https://github.com/qbitstudioai-ai/rublevka_site/commit/2246a6c8abfe7de78ebad880b86ad2e6e0d5395c)).
- [ ] **3. Публичные страницы и SEO.** Главная, проживание, беседки, баня, банкетные залы, услуги, галерея, контакты; короткие тексты, структура запросов, техническое SEO.
- [ ] **4. Контент и админ-панель.** PostgreSQL по необходимости, редактирование страниц и объектов, роли и безопасная публикация.
- [ ] **5. Бронирование проживания.** Подключение TravelLine через согласованный Booking Engine; API — только при наличии прав. TravelLine — источник истины для броней.
- [ ] **6. Мероприятия и заявки.** Афиша, регистрация, заявки на банкеты и праздники, уведомления.
- [ ] **7. Интерактивная карта.** Объекты комплекса, переходы к соответствующим разделам, мобильная версия.
- [ ] **8. Общение с гостями.** Чат с администрацией, передача диалогов оператору, затем бот.
- [ ] **9. Проверка и запуск.** Функциональные проверки, безопасность и персональные данные, производительность, SEO, мониторинг, подготовка к публикации.
- [ ] **10. Дополнительные возможности.** Личный кабинет гостя, сертификаты и другие функции — после отдельного утверждения.

## Учёт выполнения

- Этап отмечается `[x]` **только после проверки результата и объединения соответствующего PR в `main`**.
- Рядом с завершённым этапом сохраняется ссылка на PR или коммит.
- При изменении объёма работ этот файл обновляется без создания дублирующих планов.
- До отдельного решения руководителя не публиковать новый сайт вместо действующего `rublevka34.com`.

**Принципы для всех этапов:** минимум текста, сильный визуал, реальная информация об объекте, SEO без переспама, высокая скорость на мобильных устройствах.
