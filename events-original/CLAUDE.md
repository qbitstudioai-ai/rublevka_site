# Правила проекта «Рублёвка»

- Сначала изучай задачу, существующие файлы и ограничения; только затем меняй проект.
- Не усложняй архитектуру и не добавляй зависимости без подтверждённой необходимости.
- Проектируй mobile-first и обязательно проверяй адаптивность desktop- и mobile-версий.
- Не создавай generic AI-generated UI, типовые admin-dashboard или Bootstrap-композиции.
- Используй только согласованные цвета, шрифты, компоненты и фотостиль из `DESIGN_SYSTEM.md`.
- Для UI/UX применяй project-level skill `.claude/skills/rublevka-ui-design/SKILL.md`.
- Не меняй согласованную архитектуру самостоятельно; спорные решения сначала фиксируй как предложение.
- После изменений запускай все доступные проверки и сообщай, что именно проверено.
- Комментарии и документацию пиши на русском языке там, где это уместно.
- Не реализуй API, БД, Telegram, Excel, админпанель или LLM-функции без отдельного этапа и явного задания.
- Схему SQLite меняй только новой SQL-миграцией в `db/migrations/`; применённые миграции не редактируй.
- Цены храни и считай только в целых копейках; итог регистрации считает сервер.
